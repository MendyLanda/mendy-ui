I'm Mendy Landa. I put these components here so I can reuse them across projects. I maintain one npm package and use it across my projects. You can use it too.

There's one component so far, Filters. Define filters once to get editable chips, suggestions, dynamic options, paste recognition, and URL persistence.

## State

Use the supplied local or URL state hook, or bind your existing application state. Your app decides how applied values affect its data.

Update the package dependency to bring shared improvements into a project. Review the [changelog](https://github.com/MendyLanda/mendy-ui/blob/main/CHANGELOG.md), test, and deploy that project.

## Supported stack

- React 19 and TypeScript.
- Compiled, scoped CSS with shadcn semantic color variables. Tailwind is optional in the consuming app.
- Bundled Radix-based shadcn controls.
- Next.js and Vite React applications.

React 19, Next.js, and Vite are checked against the built npm tarball. Custom controls must satisfy the documented replacement contracts.
