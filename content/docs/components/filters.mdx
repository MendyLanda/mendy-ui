Open the filter menu to choose a field. Hover previews its editor without taking focus; click or keyboard entry lets you change it. Selections apply immediately and the menu stays open. On phones, Back returns to the list.

The example filters issue data and saves applied values in the URL. Paste an ID such as `UI-042`, or type it and press Enter, to create an Issue ID chip. Dashed suggestions apply on the first click and open for editing on the next. Click Clear all after the chips to reset filters and search.

## Start with definitions

<InstallCommand />

```tsx
import { defineFilters, filter, FilterBar, useFilters } from "@mendylanda/ui/filters";

const definitions = defineFilters({
  status: filter.select({
    label: "Status",
    searchable: false,
    options: [
      { value: "open", label: "Open" },
      { value: "closed", label: "Closed" },
    ],
  }),
});

export function IssueFilters() {
  const filters = useFilters(definitions);
  return <FilterBar filters={filters} />;
}
```

Import the stylesheet once using the [installation guide](/docs/installation). Use `filters.values` and `filters.search` in your data query. For URL state, replace `useFilters` with `useUrlFilters` from the optional nuqs entry point.

You get editing, removal, search, focus management, suggestions, loading summaries, and Clear all from the bar. See [defaults and app configuration](/docs/defaults) for the complete behavior and its overrides.
