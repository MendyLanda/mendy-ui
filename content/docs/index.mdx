I'm Mendy Landa. I put these components here so I can reuse them across projects. You can install them with the shadcn CLI too.

There's one component so far, Filters. Define filters once to get editable chips, suggestions, dynamic options, paste recognition, and URL persistence.

## State

Use the supplied local or URL state hook, or bind your existing application state. Your app decides how applied values affect its data.

Changes to this registry do not automatically update source already installed in your app. Review the [changelog](https://github.com/MendyLanda/mendy-ui/blob/main/CHANGELOG.md) and compare local changes before reinstalling.

## Supported stack

- React 19 and TypeScript.
- Tailwind CSS 4 with shadcn semantic color variables.
- Radix-based shadcn components.
- Next.js and Vite React applications.

Base UI and older React or Tailwind versions are not part of the initial compatibility target.
