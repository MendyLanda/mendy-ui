Mendy UI is an open source collection of React components by Mendy Landa. Install the source into your app with the shadcn CLI, then adapt it to your design.

The first component is **Filters**: editable filter chips, reusable editors, and independent remove controls.

## Start with filters

<InstallCommand />

[Try the interactive demo](/docs/components/filters), follow the [installation guide](/docs/installation), or browse the [examples](/docs/examples).

## Composition and ownership

The component handles editing interactions. Your app owns filter values, data fetching, URL persistence, and query semantics. Use it with a table, a list, a search page, or another interface.

Changes to this registry do not automatically update source already installed in your app. Review the [changelog](https://github.com/MendyLanda/mendy-ui/blob/main/CHANGELOG.md) and compare local changes before reinstalling.

## Supported stack

- React 19 and TypeScript.
- Tailwind CSS 4 with shadcn semantic color variables.
- Radix-based shadcn primitives.
- Next.js and Vite React applications.

Base UI and older React or Tailwind versions are not part of the initial compatibility target.
