I build components I want to use in my own projects, then keep their behavior in one package. Mendy UI currently has two: **Table** and **Filters**. You can use either on its own or connect them.

## Choose a component

| Component                           | Start here                                      | What it owns                                                                                 |
| ----------------------------------- | ----------------------------------------------- | -------------------------------------------------------------------------------------------- |
| [Table](/docs/components/table)     | Supply rows, typed columns, and stable row IDs. | Rendering, virtualization, sorting, column controls, selection, copying, and loading states. |
| [Filters](/docs/components/filters) | Define fields and choose a state hook.          | Search, option editors, applied chips, recognition, focus, and optional URL persistence.     |

Your application owns its data queries, permissions, mutations, and matching rules. Neither component requires a particular API or router.

## Install once

<InstallCommand />

```tsx
import "@mendylanda/ui/styles.css";
```

Both components share the stylesheet and your application's theme. Use React 19 and TypeScript. Tailwind is optional; Next.js and Vite consumers are tested against the built package. The [installation guide](/docs/installation) covers framework setup and Tailwind 3.

## Pick your level of control

Start with `DataTable` or `FilterBar`. They assemble the standard interactions. When your application already owns state, connect `useDataTable` or `useControlledFilters`. When you need another layout, compose the exported parts around the same controller.

A table does not require filters. A filter bar does not require a table. Passing a filter controller to `DataTable` connects the toolbar and empty-state recovery; you still supply the matching rows.
